# MeteoSwiss MCP Server Demo

Welcome to the MeteoSwiss MCP Server - your gateway to Swiss weather data through the Model Context Protocol.

This hosted service provides weather forecasts, real-time measurements, and more from MeteoSwiss (the Federal Office of Meteorology and Climatology) via the MeteoSwiss Open Data platform. It's designed to work seamlessly with AI assistants like Claude Desktop and Claude.ai, allowing natural language queries about Swiss weather conditions.

## Key Features

- **Multi-day Forecasts**: Weather forecasts for ~6000 Swiss locations (postal codes, stations, place names)
- **Real-time Measurements**: Live data from ~160 automatic weather stations, updated every 10 minutes
- **Station Discovery**: Search and browse the MeteoSwiss station network by name, canton, or coordinates
- **Pollen Monitoring**: Current pollen concentration data for allergy sufferers
- **MCP Compatible**: Works with any MCP-enabled AI assistant
